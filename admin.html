1️⃣ Fleet — drag foto dari kanan ke card di bawah

Drop foto ke card untuk ganti. Urutan bisa drag card-nya juga. Klik ✏️ untuk edit nama/harga.

Cara pakai: Geser foto dari galeri kanan → drop ke card. Atau upload foto baru di galeri. Klik Simpan → download index.html baru, upload ke GitHub (drag ke repo → Commit).

Tips: foto asli sebaiknya 800x600, < 500KB. Nama file otomatis: scoopy.jpg, vario125.jpg dll.
