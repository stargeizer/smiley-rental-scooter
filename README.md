## Ganti nomor WA (1 baris)
Edit `index.html` baris ~14:
```js
window.SMILEY_WA="6281234567890";
window.SMILEY_PHONE_DISPLAY="+62 812-3456-7890";
```
Atau buka `https://your-site.com/?wa=6281234567890` untuk test.

Semua tombol BOOK NOW otomatis pakai nomor ini.
